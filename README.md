Phoenix v1.1.1 — Runtime Expansion & Cross-Platform Foundation Release

Overview

Phoenix v1.1.1 is a major development milestone for the Phoenix programming language, introducing improvements across the compiler pipeline, virtual machine architecture, standard libraries, and platform support.

This release strengthens Phoenix as a modern systems-oriented programming language designed for building applications ranging from command-line tools and desktop software to operating system components and native extensions.

Highlights

🚀 Improved Compiler Architecture

- Enhanced lexer, parser, and compiler pipeline stability.
- Improved handling of Phoenix syntax structures.
- Expanded internal compiler organization for future language features.
- Better diagnostic and error reporting foundations.

⚡ Virtual Machine Improvements

- Improved VM architecture and execution flow.
- Enhanced memory management foundations.
- Continued development toward a high-performance runtime environment.
- Better separation between runtime components.

🔗 Native System Integration

- Added improvements to Phoenix native bridging capabilities.
- Expanded support for interacting with system-level APIs.
- Strengthened foundations for future native extensions and platform modules.

🖥️ Windows Build Support

- Added Windows x86_64 build configuration.
- Phoenix can now be cross-compiled for Windows environments.
- Improved compatibility with LLVM/Clang-based toolchains.
- Established the foundation for native Phoenix applications on Windows.

📦 Standard Library Growth

- Expanded core libraries and system modules.
- Improved organization of built-in functionality.
- Continued preparation for a larger Phoenix ecosystem.

Developer Experience

Phoenix v1.1.1 focuses on making the language easier to build, extend, and contribute to:

- Cleaner project structure.
- Improved CMake build system.
- Better cross-platform compilation support.
- More maintainable compiler and runtime codebase.

Build Targets

Current supported targets:

✅ Linux
✅ Termux/Android development environments

Additional platforms are planned as Phoenix continues evolving.

What's Next

Future Phoenix releases will focus on:

Installation

Clone the repository:

git clone https://github.com/Asonsoft-phoenix-language.git
cd phoenix

Build with CMake:

mkdir build
cd build
cmake ..
cmake --build .

About Phoenix

Phoenix is a modern programming language created by Asonsoft, designed with a focus on performance, developer freedom, system programming, and future operating-system-level development.

Phoenix aims to provide a powerful environment for creating everything from applications to low-level system software.
